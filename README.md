This is my personal resume website, designed to showcase my experience as a financial analyst across real estate and capital markets. Built with HTML, CSS, and JavaScript, it is optimized for fast, responsive browsing and deployed via Cloudflare Pages.

## 🔗 Live Website
👉 [Visit my website](https://2d52cdb0.resume-website-abx.pages.dev/)

## 📝 About
Based in Orange County, CA, I focus on DCF modeling, real estate loan underwriting, project research and projections, and commercial and multifamily operations. The site covers my experience, financial and real estate skills, education, credentials, and interests in travel, history, and architecture.

## 🛠 Tech Stack
- **HTML5**: Semantic structure & content
- **CSS3**: Custom styling & responsive design
- **JavaScript (Vanilla)**: Rotating role typewriter with reduced-motion support
- **Cloudflare Pages**: Static hosting with CDN delivery

## Local preview

Run `python3 -m http.server 8000` from the project directory, then open `http://localhost:8000`. No build step is required. The Download CV button serves `assets/resume.pdf`.
